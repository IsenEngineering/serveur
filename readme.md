# Accueil

Cet espace contient toutes les procédures, documentations et informations officieles relatives au serveur de l'IE. 

Ces documents sont modifiables directement depuis [le dépôt github](https://github.com/IsenEngineering/serveur) de l'association,
on utilise le système de Pull-Request pour avoir un système d'authorité et de versionnage.

Tous les documents suivent la forme suivante.
> #### Nomenclature
> PROXX -> Procédure N°XX\
> DOCXX -> Documentation N°XX\
> INFXX -> Fiche d'information N°XX
