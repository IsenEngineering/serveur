## Introduction

Tidee est le système de gestion de présence de l'IsenEngineering.
Chaque responsable y atteste toutes semaines le nombre d'heures que passe les membres de leur pôle.

## Structure

Cette plateforme a évolué avec le temps au fil des besoins.
Son développement est actuellement en pause, en attente qu'une brave personne souhaite la faire évoluer / reconstruire.

La plateforme est construite avec [Qwik](https://qwik.dev), à l'époque du développement ce framework JavaScript était une solution qui remplissait tous les besoins. L'interface et le backend utilise Qwik; L'un des points forts de ce framework est sa complicité entre le frontend et le backend (*à voir par vous même en ouvrant l'inspecteur dans l'onglet réseau).

Le choix de la base de données c'est tourné vers [SurrealDB](https://surrealdb.com), ce choix était un pari, qui semble être gagnant en mars 2026.
